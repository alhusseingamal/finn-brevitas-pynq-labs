## Commands

### Run Model Training and Export
#### The following command traina a model with parameters: 12x12 images, 2-bit width, 3-bit activation, 3 conv layers with channel dimensions 12, 24, 36
python train_dse.py --img_size 12 --epochs 100 --wbits 2 --abits 3 --channels 12 24 36 > model-dse-logs/12x12_w2a3_c12x24x36.log 2>&1 &

The created (.pt and .onnx) model formats are saved to ./models directory

#### Use FINN to build the model for hardware at a target_fps of 800000
finn build build_gtsrb_12x12_w2a3_c12x24x36_fps800000.yaml > 12x12_w2a3_c12x24x36_fps800000.log 2>&1 &

The .yaml file defines parameters and build steps for the FINN build, and may point to the file with custom folding parameters

### There is another way to configure a finn build: using a build.py file

from finn.builder.build_dataflow_config import DataflowStepBuilder
import finn.builder.build_dataflow as build
import finn.builder.build_dataflow_config as build_cfg
from transform_input import step_transform_input

custom_steps = DataflowStepBuilder()
custom_steps.insert_after("step_qonnx_to_finn", step_transform_input)

cfg = build_cfg.DataflowBuildConfig(
    output_dir="finn_output_12x12_w2a3",
    target_fps=10000,
    synth_clk_period_ns=10.0,
    board="Pynq-Z2",
    steps=custom_steps.build(),
    shell_flow_type=build_cfg.ShellFlowType.BITFILE,
    generate_outputs=[
        build_cfg.DataflowOutputType.ESTIMATE_REPORTS,
        build_cfg.DataflowOutputType.BITFILE,
        build_cfg.DataflowOutputType.PYNQ_DRIVER,
    ],
)

### Target Exp 6 (12x12 W2A3 @ 97.36%) or Exp 2 (12x12 W3A3 @ 98.91%)
build.build_dataflow_cfg("models/gtsrb_12x12_w2a3_c16-32-64.onnx", cfg)
